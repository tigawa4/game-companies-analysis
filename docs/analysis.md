# ゲームメーカー3社の収益性・利益構造に関する分析

## 分析の目的と前提

### 比較対象企業
- 任天堂株式会社
- 株式会社カプコン
- コーエーテクモホールディングス

### 比較対象年度
- 会計年度 2016年度～2025年度

会計年度は期首日における年度で表す(例:2025年度は2025年4月1日～2026年3月31日)

### 想定利用者
- 想定利用者は架空の大手ゲームメーカーの経営企画・財務担当者

### 目的
- 他社の収益性・利益構造を明らかにすることで、自社の戦略立案や課題発見につなげる

ただし、架空の自社データを用意していないため、他社の分析を主目的としている

### 出典
- EDINETの有価証券報告書から取得した日本基準の連結財務データ

### 注意事項
- 表示値には丸めがあるため、差や合計が厳密に一致しない場合がある

## 1. 任天堂：大幅な増収と営業利益率の低下が同時に起きた

### 事実

2024年度から2025年度にかけて売上高がほぼ倍増した一方、営業利益率は24.3%から15.6%へ低下した

- 売上原価率：39.0% → 60.7%（+21.7pt）
- 売上総利益率：61.0% → 39.3%（-21.7pt）
- 販管費率：36.7% → 23.7%（-13.0pt）
- 営業利益率：24.3% → 15.6%（-8.7pt）

※2024年度から2025年度への変化。

### 解釈

営業利益率 = 売上高総利益率 - 販管費率

この期間は、売上高に対する販管費の割合が低下したものの、それを上回る幅で売上総利益率が低下している

したがって、比率の変化を分解すると、営業利益率低下の主な要因は売上原価率の上昇にあると考えられる

ただし様々な要因が考えられ、この集計だけでは判断できない

- 商品構成の変化 : 利益率の低い商品の販売割合が増えた可能性

- 単価・採算の変化 : 仕入原価の上昇や値下げにより、各商品の採算が悪化した可能性

例えば、ハードとソフトの比率変化や新作・次世代機サイクルのタイミングなどが考えられる

※ただし、比率の増加減少は，金額の増加減少を必ずしも意味しない点は注意が必要

### 自社分析への示唆

増収計画を評価する際は、売上規模と併せて、商品別の売上構成と粗利率を確認する必要がある。

自社で同様の変化が起きた場合は、次の二つを切り分けることが出発点になる。

- 粗利率の低い商品の売上構成比が高まった影響

- 個々の商品・事業の粗利率が低下した影響

※ただし、利益率が低下しても、売上規模の拡大により利益額が増える場合があり、
営業利益額とその前年比も併せて評価する必要がある

## 2. カプコン：利益率が伸びた時期と高水準を維持した時期がある

### 事実

2016年度から2019年度にかけて、営業利益率は15.7%から28.0%へ上昇した

この間、売上原価率は64.7%から49.8%へ低下する一方、販管費率は19.6%から22.2%へ上昇した

2019年度には売上高が前年比18.4%減少したが、営業利益率は上昇している

その後の2020～2025年度は毎年度増収となり、営業利益率はおおむね36～40%台の高水準で推移している

### 解釈

2016～2019年度の営業利益率改善は、主に売上原価率の低下、すなわち売上総利益率の上昇によって説明できると考えられる

また、2019年度の動きは、売上高の成長と利益率の改善が必ずしも同時に起きないことを示している

一方、2020年度以降は、売上を伸ばしながら高い営業利益率を保った期間として捉えることができる

### 自社分析への示唆

自社の状況を、利益率を引き上げる段階と、高い利益率を維持しながら売上を伸ばす段階に分けて評価する

- 利益率の改善 ： 商品・事業別の粗利率、売上構成、原価の内容を確認する

- 高い利益率を維持した成長 ： 売上拡大に伴う粗利率・販管費率の変化と、営業利益額を確認する

※具体的な要因は、事業別情報や販売構成などを追加確認する必要がある

## 3. コーエーテクモ：営業利益と経常利益を分けて評価する必要がある

### 観察した事実

コーエーテクモホールディングスは、３社の中では売上総利益率、営業利益率が最も高い水準にある

経常利益率で比較すると、その差はさらに広がる

コーエーテクモでは、分析期間を通じて経常利益率が営業利益率を上回る傾向が見られる

また、2022年度から2023年度には、営業利益率が49.9%から33.7%へ低下する一方、経常利益率は50.9%から54.1%へ上昇した

### 解釈

経常利益率の高さには、営業活動の利益率だけでなく、営業外損益の寄与もある

2022～2023年度のように営業利益率と経常利益率が逆方向に動く年度では、経常利益率だけを見ていると、営業活動の採算低下を見落とす可能性がある

- 属人生の問題 : 襟川恵子氏(名誉会長・株式会社コーエーテクモコーポレートファイナンス代表取締役社長)の投資手腕に依る側面が強いと考えられる

- 再現性の問題 : 金融市場の動向により営業外損益が大きくぶれる可能性がある

### 自社分析への示唆

営業活動(本業)の収益性を比較する目的であれば営業利益率を用いる必要があると考えられる

全社の利益構造を把握することを目的として経常利益率を用いる際は資産運用のパフォーマンスなどに影響されることに注意する必要がある

経常利益を恒常的な収益力と誤認しないように注意が必要

## 分析から得られた比較の視点

3社の比較から、収益性を評価する際には次の視点を組み合わせる必要があると考えられる

- 売上成長と利益率を分けて見る：増収だけでは採算の改善は判断できない

- 比率と金額を併せて見る：利益率の変化と利益額の変化が一致するとは限らない

- 営業利益率を粗利率と販管費率に分解する：比率の改善・悪化がどこに表れているかを確認する

- 営業利益と経常利益を分けて見る：営業外損益が全社利益に与える影響を把握する

## 分析の限界

- 対象は3社・10年度の連結財務データであり、業界全体の傾向を代表するものではない

- 丸めの誤差を含み、厳密な差の比較には元データの確認が必要

- 商品構成、原価の内訳、営業外損益の具体的な内訳は追加で調査する必要がある

- 企業ごとの事業構成や会計上の扱いが異なるため、比率の差をそのまま経営効率の優劣とは判断できない

- 個別プロットの散らばりには年度の推移も含まれる。分布の広さだけで業績の不安定さを判断せず、時系列グラフと併せて確認する必要がある
